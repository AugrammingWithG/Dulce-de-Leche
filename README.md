# Dulce-de-Leche

Website for Dulce de Leche Cafe: the customer site and the staff counter view.

## Run it

```
npm install
npm run dev
```

- Customer site: `/`
- Counter view: `/admin.html`
- Self-test: `/selftest.html`

`npm run build` writes the production site to `dist/`.

The site source lives in `dulce-de-leche/`. See `HANDOFF.md` for how it's put together and what changes before launch.
